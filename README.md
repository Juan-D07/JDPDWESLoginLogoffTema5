
# Aplicación de Proyecto Login Logff Tema 5
## 1. Descripción
Esta aplicación web está desarrollada en PHP y hacemos uso de la sesion y cookies.
Aunque parezca una aplicacion sobre control de acceso nuestro enfoque es el uso de las sesiones y las cookies. 

## 2. Requisitos
- PHP 8.3 o superior.
- Un servidor web, como Apache, o el servidor de desarrollo integrado de PHP.
- MySQL si la aplicación utiliza una base de datos.
## 3. Instalación
Clonar el repositorio:
`git clone https://github.com/Juan-D07/JDPDWESLoginLogoffTema5`

Acceder a la carpeta del proyecto:
`cd JDPDWESLoginLogoffTema5`
*Configurar la conexión a la base de datos en config.php y ejecuta los sricpts de creacion y carga.*

Iniciar el servidor de desarrollo de PHP:
`php -S localhost:8000`

## 4. Uso
Una vez iniciado el servidor:

Abrir un navegador web.
`Acceder a http://localhost:8000.`
Crear nuevas tareas y gestionar las existentes.

## 6. Funcionalidades
- Uso de sesion y cookies
- Practica de control de acceso
- Creacion, edicion, y eliminacion de usuarios
